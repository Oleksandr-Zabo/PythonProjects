# Django DZ (08/dz/src)

## Завдання 1
Налаштуйте додаток з другого завдання, щоб він виводив у браузер поточну дату та час.

## Завдання 2
Створіть вебдодаток для відображення таблицю множення від 1 до 10.

## Завдання 3
Створіть вебдодаток для відображення дати дня програміста у поточному році. День програміста — 256-й день року.

## Що реалізовано
- Головна сторінка `/` показує поточну дату та час.
- Сторінка `/table/` показує таблицю множення 1..10.
- Сторінка `/programmer-day/` показує дату 256-го дня поточного року.

## Структура
- Django проект запускається з папки `08/dz/src`.
- Головні модулі:
  - `manage.py`
  - `core/settings.py`
  - `core/urls.py`
  - `feachers/views.py`
  - `feachers/urls.py`
  - `feachers/templates/feachers/*.html`

## Встановлення
Виконуйте команди з кореня репозиторію або перейдіть у `08/dz`.

```powershell
pip install -r config/requirements.txt
```

## Запуск (Django run in src)
```powershell
cd src
python manage.py runserver
```

Після запуску відкрий у браузері:
- http://127.0.0.1:8000/
- http://127.0.0.1:8000/table/
- http://127.0.0.1:8000/programmer-day/

## Перевірка конфігурації
```powershell
cd src
python manage.py check
```
