# PythonProjects CRUD API
FastAPI apps:
- 07/dz/Recipe/main.py
- 07/dz/Shoes/main.py
Install:
```powershell
pip install -r requirements.txt
```
Run Recipe:
```powershell
cd 07\dz\Recipe
python main.py
```
Run Shoes:
```powershell
cd 07\dz\Shoes
python main.py
```
Docs:
- Recipe: http://127.0.0.1:8000/docs   or http://127.0.0.1:8000/redoc 
- Shoes: http://127.0.0.1:8001/docs    or http://127.0.0.1:8001/redoc
